# H.S. Traders Office 1.7.3

Android package `com.hstraders.office`, versionCode `16`.

The entire Android app now uses an iOS-inspired white-and-blue appearance:

- White screens and cards, neutral grey search fields and icon surfaces, black
  text, fine separators and clear blue actions. The home task summary, hamburger
  menu, forms, task cards, report screens and account settings share the theme.
- Larger headings, simpler type styling and rounded rectangular buttons replace
  heavy navy panels and pill-shaped primary controls.
- Simple centered white confirmation dialogs replace the bottom sheets. They use
  black headings, grey descriptions, blue text buttons and thin dividers, with no
  decorative icon, blue tint or filled button. Destructive actions use red text.
- Task and party widgets share the white-and-blue colors. Widget task completion
  uses the same centered dialog design.

Navigation, task completion safeguards, report generation, PDF sharing and data
remain unchanged. Reduced motion, long dialog messages and safe cancellation
remain supported.
